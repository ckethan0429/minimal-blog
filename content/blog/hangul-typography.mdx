한국어와 영어를 한 페이지에 섞어 쓸 때, 글자가 **깨지거나** 간격이 들쭉날쭉하면 읽기가 금방 피곤해집니다.

## 원칙

- **같은 산세리프 계열**로 한글·라틴을 맞춥니다. 이 사이트는 나눔스퀘어 네오를 씁니다.
- 본문 줄간격은 라틴 전용보다 조금 넉넉히 (`1.8` 전후).
- 자간을 세게 줄이지 않습니다. 한글 블록이 뭉쳐 보이기 쉽습니다.
- `word-break: keep-all`로 어절 단위 줄바꿈을 선호합니다.

## 코드 안의 한글

```ts
// 사용자에게 보이는 메시지
const greeting = "안녕하세요, 엔지니어입니다.";
console.log(greeting);
```

입력창에서도 같은 글꼴을 쓰도록 `font-family: inherit`을 걸었습니다. 타이핑할 때 미리보기와 화면이 어긋나지 않게 하려는 목적입니다.

## 마치며

타이포그래피는 장식이 아니라 **읽기 경험**입니다. 한글이 먼저 부드럽게 보여야, 영문 노트도 같이 편해집니다.
