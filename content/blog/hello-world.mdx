Welcome. This is a personal blog for software engineers who care about the craft.

## What this is

I write about building products that feel fast, stay maintainable, and treat users with respect. Expect essays on:

- Web performance and Core Web Vitals
- System design trade-offs
- TypeScript, React, and modern tooling
- Accessibility as a first-class constraint

## What this is not

There is no CMS. No database. Posts live as Markdown files in the repository, versioned like code, reviewed like code, deployed like code.

That constraint is intentional. It keeps the surface area small and the feedback loop short.

## How to read

Start with the [blog index](/blog), or jump into a deeper piece when you have twenty quiet minutes. Everything here is meant to be read carefully — not skimmed between notifications.

Thanks for stopping by.
